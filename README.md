# Laurand Osmeni — Engineering Command Deck

Laurand Osmeni’s personal software engineering portfolio is presented as an interactive science-fiction command deck. It introduces his background, technical abilities, professional experience, education, and selected software products through a fast, responsive interface.

## What the Site Does

- Presents Laurand’s software engineering and leadership profile.
- Showcases mobile applications and web development projects.
- Highlights C++, JavaScript, HTML, CSS, Python, Java, TypeScript, and SwiftUI development.
- Displays professional experience, education, technical systems, and tools.
- Runs two animated terminals: a software developer activity log and an exoplanet exploration mission.
- Provides direct links to Laurand’s GitHub and Apple App Store portfolio.
- Includes a contact form that sends messages without taking visitors away from the site.
- Provides concise Privacy, Terms, and About information.
- Works across desktop, tablet, and mobile screen sizes.

## Website Files

- `index.html` contains the portfolio structure and content.
- `styles.css` provides the red, yellow, black, and steel science-fiction design.
- `script.js` controls navigation, terminals, sounds, dialogs, and contact delivery.
- `assets/laurand-graduation.webp` is the portfolio profile image.

Website created by Laurand Osmeni.

The website uses no external libraries, fonts, trackers, or remote assets.
